## YouTube Automation Tool — Pipeline Automatizado de Vídeos (SaaS Fullstack)

**Data de Inicio:** 01/2026  
**Data de Término:** Em desenvolvimento
**Descrição:** Desenvolvi uma plataforma SaaS completa para automação da criação e publicação de vídeos no YouTube, centralizando todo o pipeline de produção em uma única aplicação. O projeto foi idealizado e estruturado com o auxílio de Inteligência Artificial, principalmente na definição de arquitetura, regras de negócio e otimização do fluxo de desenvolvimento.

A solução automatiza etapas críticas do processo de criação de conteúdo, incluindo merge de vídeos, transcrição automática, geração de SEO (título, descrição e tags), criação de thumbnails com IA e upload direto para o YouTube. Todo o processamento pesado é executado no backend, garantindo performance, segurança e escalabilidade.

Implementei um pipeline orientado a estados com controle por jobId, validação de etapas e comunicação em tempo real via SSE (Server-Sent Events), permitindo acompanhar processos longos como transcrição e processamento de vídeo. O sistema também conta com filas em memória para controle de concorrência (FFmpeg e Whisper), preparando a base para evolução futura com workers distribuídos.

A plataforma inclui um modelo de monetização baseado em créditos e assinatura (Stripe), com controle rigoroso no backend, além de um painel administrativo para configuração de modelos de IA, chaves e limites operacionais.

Principais funcionalidades:
Pipeline completo de automação de vídeos (upload → merge → transcrição → SEO → thumbnail → upload YouTube)
Integração com IA (OpenAI, Ollama, Whisper, geração de imagens)
Processamento de mídia com FFmpeg
Upload automatizado via YouTube Data API
Sistema de créditos e assinatura (Stripe)
Controle de concorrência com filas e rate limiting
Segurança com JWT, criptografia de credenciais e validação server-side

Tecnologias utilizadas:
Node.js, Express, TypeScript, React 19, Vite, Tailwind CSS, Supabase (Auth + PostgreSQL), FFmpeg, faster-whisper (Python), OpenAI / Ollama, DALL-E / Stable Diffusion, Stripe, SSE (ReadableStream).
